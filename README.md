# CXStudy 超星助手

一个只面向**超星学习通**（chaoxing.com / xueyinonline.com）的课程学习辅助用户脚本。

本项目基于 [OCS 网课助手](https://github.com/ocsjs/ocsjs)（MIT 协议）**收敛范围**后的衍生分支：
复用上游成熟的答题框架与题型匹配算法，去掉其他平台的全部代码，
并把答题来源从"题库"改为**你自己的大模型 API**。

> 仅供个人学习研究使用，请自行承担使用风险（详见 [风险说明](#风险说明请务必阅读)）。

---

## 功能

| 功能 | 说明 |
|---|---|
| 视频 / 音频 / 文档任务点 | **以 1.0x 真实速率**自动推进，不使用倍速、不拖动进度、不发送协议包 |
| 章节测验 | 自动作答并提交，含**加密字体解密**与**图片题**（题干/选项是图片也支持） |
| 视频内弹题 | 优先交给模型作答；答不出时按上游方式随机兜底，避免弹题卡住播放 |
| 答不出时 | 可随机兜底（默认开，可关），避免因存在未作答题目导致整份测验无法提交 |
| 作业 / 考试 | **默认关闭**，需手动开启并逐次确认 |
| 答题来源 | 你自己的大模型 API（`opencode-go` 或 `deepseek` 官方），模型锁定 `deepseek-v4.1-flash` |

### 明确不做的事

- **不使用倍速**（恒为 1.0x）、**不拖动/跳过**播放进度、**不发送协议包**伪造进度
- **不绕过人脸识别**、**不识别或绕过验证码**：检测到即停手，交由人工完成
- **不收集、不上报任何数据**：没有统计埋点，也没有答题结果上传
- 答不出时**不做静默跳过**：要么按配置兜底，要么明确告警交回人工

## 安装

### 方式一：从链接安装（推荐）

1. 先安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（油猴）或 [ScriptCat](https://scriptcat.org/)（脚本猫）
2. 点下面的链接，脚本管理器会弹出安装界面：

   **https://raw.githubusercontent.com/Zefyro-N/CXStudy/main/ocs.user.js**

### 方式二：手动安装

下载仓库里的 `ocs.user.js`，在脚本管理器中新建脚本 → 粘贴全部内容 → 保存。

### 配置模型

打开任意超星课程页面，脚本会注入悬浮面板 → 「通用 / 全局设置」里填写：

- **模型提供商**：`opencode-go` 或 `deepseek`（官方）
- **API Key**：只保存在浏览器本地脚本存储中，**不写入任何文件、不上传任何服务器**

安装后脚本会通过 `@updateURL` **自动检查更新**。

## 风险说明（请务必阅读）

本工具会代替你完成课程学习任务。使用自动化手段存在被平台判定为异常的风险，
已知后果包括：**学习记录被清零 → 再次违规则总评 0 分 → 三次可能按作弊处理**。
请自行评估并承担全部风险。

作业与考试功能默认关闭，且属于额外风险，建议在你知情的前提下逐次手动开启。
"答不出时随机兜底"会把错答写入真实成绩，该选项可随时关闭。

## 与上游的差异

**保留**：答题框架（题目解析、题型匹配算法、面板与配置体系）、超星平台的完整功能、字体解密能力。

**移除**：

- 其他平台的全部代码与入口（智慧树、雨课堂、智慧职教、职教云、中国大学 MOOC）
- 题库体系与相关界面（改为直接接入你自己的模型 API）
- 上游的在线更新检查、更新日志、交流群 / 官网 / 捐赠等推广信息，以及 logo 与 CDN 图标
- 桌面软件配置同步、`@connect *` 的全域名通用构建变体

**改动**：视频内弹题与章节测验增加了「模型答不出时随机兜底」；
章节测验补做了加密字体解密（上游只在作业/考试页解密）。

**仍然依赖的上游资源**：字体解密参照表 `https://cdn.ocsjs.com/resources/font/*.bin`
（按需拉取并缓存；若不可达，加密字体无法解密）。

完整改动见 [`patches/`](patches/)，可用 `git apply` 应用到上游对应 commit 复现。

## 构建

需要 Node 18+：

```bash
git clone https://github.com/ocsjs/ocsjs
cd ocsjs && git checkout 8b25a3f
git apply /path/to/ocsjs-cxstudy.patch
pnpm install --node-linker=hoisted
npx gulp -f scripts/build-core.js
```

构建前会自动运行三套测试（题型匹配算法、prompt 构造器、视频弹题定位），
并校验产物中只包含超星学习通一个平台。产物输出到 `release/ocs.user.js`。
